# bomb — Scoop bucket

Free, open-source Windows apps by [bombxdev](https://github.com/bombxdev).

```
scoop bucket add bomb https://github.com/bombxdev/scoop-bucket
scoop install idea-autopilot
```

| App | What it does |
|---|---|
| [idea-autopilot](https://github.com/bombxdev/idea-autopilot) | Tray app that spends your spare AI-agent quota researching and prototyping your ideas |

Each manifest points at a GitHub Release asset and pins its SHA-256, so Scoop refuses a file that was swapped.
Your data (the app's `data` folder) is kept when you update.
